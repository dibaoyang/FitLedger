# 轻衡 FitLedger

男大学生为了方便自己减脂自己做了这个饮食规划工具

<img src="artwork/launcher-icon-source.png" alt="轻衡应用图标" width="180" />

轻衡是一款本地使用的 Android 饮食与健身记录工具：记录每天吃了什么，设置营养目标，观察身体变化，也可以用自己的食品库搭配剩余饮食。无需注册账号，没有在线账户或云同步。

当前版本 **1.9.1（versionCode 12）**。支持 **Android 8.0 及以上**；此仓库不提供 iOS 或原生 HarmonyOS 版本。这次补上两处分区功能：每个分区固定使用 g 或份，食品必须与分区单位一致；也能直接在分区管理里搜索、多选添加同单位食品。[查看 1.9.1 更新说明](UPDATE_1.9.1.md)。

## 五个页面做什么

| 页面 | 用途 |
| --- | --- |
| 今日 | 先录入当天身体数据，再按分区记录食品或直接添加碳水、蛋白质、脂肪；查看营养目标、摄入、费用、热量缺口和推荐，也可标记放纵日。 |
| 食品库 | 添加、编辑和删除食品；管理种类分区、营养标签、顺序和可选价格，可识别包装营养表，也可通过食品代码分享或导入食品。 |
| 每日吃的 | 设置固定克数、固定份数或按当天体重计算的食品克数，完成当天身体记录后自动添加，每项每天一次。 |
| 趋势 | 查看 7／30／90 天变化，展开累计体重、体脂变化与平均每日热量缺口。隐藏的身体项目同步隐藏对应数值、曲线和累计变化。 |
| 设置 | 修改饮食计划、个人资料、隐私显示、提醒和默认单位，设置推荐预算与营养范围，管理备份与恢复。 |

## 可以怎么用

- 体重可用 kg 或斤输入；体脂率输入百分数，瘦体重自动计算。肌肉量可设置免填，其他身体信息可分别控制显示或隐藏。
- 食品支持 kcal／kJ 输入和显示，应用内部统一按 kcal 计算。营养记录不区分餐次；同一种食品的自动与手动记录合计展示，也可展开修改或删除其中一次记录。
- 食品库和今日记录可切换「按种类／按营养」。g 分区只放按 g 记录的食品，份分区只放按份记录的食品，分别按实际克数或份数相加；每日上限与单次推荐上限分别填写，单位跟随本分区，不通过每份克重混放。切换分区单位需先处理不匹配食品，再重新填写上限。分区上限只限制推荐，手动摄入可如实记录。碳水、蛋白质、脂肪标签可多选，只帮助查找，不会重复计算摄入。长按排序手柄可调整分区与未分区食品的位置，也可在分区内排序。
- 在「管理种类分区」点「添加食品到本区」，只能搜索、多选与本区单位一致的食品，确认后统一加入。已有兼容成员保持原样；其他分区的同单位食品会在确认后移入，每种食品只属于一个种类分区。历史摄入不改写，今日分区额度按新的归属和原生数量统计。
- 旧分区若存在单位不一致的食品或旧份数换算，界面会提示核对，处理完成前暂停该区推荐。可明确确认将不匹配食品移到未分区，再检查分区单位和上限；食品资料及历史记录保留，不会自动换算旧限量。
- 价格可留空，也可填写每克／每份单价，或根据总价、包数和每包数量换算。摄入费用按记录时保存，修改食品价格不会重算旧记录；未知历史费用显示未计价。
- 计划支持固定宏量、碳循环、碳水渐降、身体数据计算和自定义组合，可按体重、瘦体重、固定克数、热量比例或剩余热量分配营养。
- 根据估算消耗设置缺口或盈余；运动可按爬坡、爬楼、跑步时长估算，或直接填写额外消耗。
- 智能推荐可锁定必吃数量，并结合食品上限、分区共享上限、全天预算和三大营养素的双向允许偏差；可选「性价比优先」。预算扣除今日已记费用，未计价食品不能用于预算或性价比推荐，当天有未计价摄入时也无法保证预算。有限搜索可能找不到可行组合，不能保证全局最低价。
- 「每日吃的」支持启用、停用和删除固定项；修改固定项不会改写已产生的摄入。今日删掉自动记录后不会自动补回来，需要时可手动补记。
- 「今天是放纵餐」可将今日页切换为提示页，保留身体、饮食和目标，随时恢复。该日期不计入平均每日热量缺口。
- 趋势日均按总消耗减已记摄入计算，只统计今天之前有饮食和总消耗记录、摄入不少于 1000 kcal 且未标记放纵日的日期；不是按缺口是否达到 1000 kcal 筛选。摄入超过消耗时显示热量盈余。
- 食品代码只分享单项食品资料，不包含身体或饮食历史；本地价格、分区和营养标签不随现有食品代码分享。导入会新增食品，不覆盖原有记录。

## 第一次使用

1. 阅读首次须知，填写「首次设置」中的个人资料。已有资料的升级用户不必重复填写首次设置。
2. 每天先录入体重和体脂率；肌肉量默认要求填写，可点击「隐藏并免填肌肉量」或在设置关闭该要求。保存后生成当天营养目标。
3. 到食品库添加自己实际会吃的食品，填写食品包装或自己核对的营养资料。
4. 在今日页按实际吃掉的克数或份数记录；已知三大营养素时，也可展开「直接添加营养」填写克数并点击添加。每天固定吃的食品可在「每日吃的」设置自动记录，仍需核对当天实际摄入。
5. 在设置配置自己的计划。正常保存明天生效；「立即生效」经确认后重算今天的目标，保留已记录的饮食和历史日期。

首次示例目标只是默认设置，不是根据个人健康情况给出的饮食建议。体脂率如为 15.2%，输入 `15.2`；瘦体重按 `体重 × (1 − 体脂率 ÷ 100)` 计算。

## 包装营养表识别

新增或编辑食品时，可以拍照或从系统照片选择器选图。中文文字识别模型内置在 APK 中，在本机处理；当前发行包不申请联网权限，不上传识别照片，也无需下载模型。

识别会先产生可修改的草稿，**请对照包装核对后再保存**，特别注意 kcal／kJ、每 100g／每份、小数点和 NRV%。缺失或不明确的数值不会猜测。每 100mL 不能直接当成每 100g，需要人工确认计量方式。这项功能读取包装上的文字，不能从一盘菜推算配方和营养。内置模型会增加安装包大小。

## 数据与隐私

身体、食品、饮食、运动、计划、价格、每日固定项和偏好保存在本机应用私有存储中。身体显示／隐藏只改变界面，不删除真实数据，也不停止计算。照片在本机识别；拍照临时文件在处理结束或取消后清理，原相册图片不改动。

设置中的导出备份包含身体历史等重要信息，当前为**没有独立密码加密的 JSON 文件**。请保存在自己控制的位置，不要上传到公开仓库、Issue 或聊天群。系统文件选择器选择云盘等位置时，该文件由相应服务保管。卸载、清除数据或设备损坏后，开发者没有云端副本可以恢复，需依靠自己另存的备份。

详细处理方式见 [使用条款与隐私说明](TERMS_AND_PRIVACY_1.8.md)。发布者：**猪肚鸡**；反馈与隐私联系邮箱：**2239254611@qq.com**。

## 结果的适用范围

食品标签、称量、配方、身体测量和活动系数都会影响结果。BMR、运动消耗、热量缺口及推荐组合均为估算或计算参考，不能替代专业医疗或营养建议。

「今日实际热量缺口／盈余」随已记录摄入更新；没有记完当天所有食品时，它不代表全天最终缺口。平均每日热量缺口也依赖记录是否完整。初始示例计划和其他人分享的食品资料需要自己核对。
